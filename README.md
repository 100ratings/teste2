# Notas PWA — protótipo para iPhone

Protótipo estático inspirado diretamente na captura fornecida, preparado para GitHub Pages.

## O que foi ajustado

- Os controles fixos agora vêm de `ios-chrome.png`, uma camada recortada diretamente do print enviado.
- A barra de status foi removida e a área superior fica preta.
- Os botões são apenas visuais e não executam ações, como solicitado.
- Somente a área das 10.000 palavras se move com rolagem.

## Publicar no GitHub Pages

1. Envie todos os arquivos desta pasta para a raiz de um repositório.
2. Abra `Settings > Pages`.
3. Selecione `Deploy from a branch`, branch `main` e pasta `/ (root)`.
4. Abra o endereço gerado no Safari do iPhone.
5. Use `Compartilhar > Adicionar à Tela de Início`.

O arquivo `words.txt` contém exatamente as 10.000 palavras exibidas, uma por linha.
